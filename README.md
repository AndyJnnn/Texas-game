# 德州扑克

无限注德州扑克，4 到 7 人。可以单机打，也可以在这台电脑开一个房间，朋友用浏览器加入，空位由电脑补上。

每人开局 1000。小盲 10，大盲 20。你固定坐在下方。

## 怎么开

单机：用浏览器打开 `index.html`，选人数，点「本地对局」。

联机需要 [Node.js](https://nodejs.org/)，不用安装别的包。在这个目录运行：

```bash
node server.js
```

终端会打印地址。自己打开 `http://127.0.0.1:8787`。朋友打开同一网段下打印出来的那个地址，不要用 `127.0.0.1`。房主创建房间，把 4 位房间号给朋友。空位自动由电脑坐下。直接双击 `index.html` 时，创建房间和加入房间不可用。

端口是 8787。如果提示地址已被占用，说明服务已经在跑，直接打开上面的地址。

规则自检：

```bash
node engine.js
```

打印 `selfCheck ok` 即通过。

## 牌局

庄家、盲注和行动都顺时针。只剩两人时，庄家兼任小盲。筹码归零的人下一手旁观。本地对局里你输光，这桌就结束。联机时你输光可以旁观，其他人继续。

轮到你时可以弃牌、过牌或跟注。加注用 5、10、20、50、100 的筹码点出来，总额是 5 的倍数。跟注按欠下的原数，不取整。筹码不够完成最小加注时，可以把剩下的全部推完；这个零头不必是 5 的倍数，也不算一次完整加注，已经行动过的人不能因此重新加注。最小加注从大盲 20 起，每次完整加注会把它抬高。

「拆」把一张筹码换成更小的，「合」再换回去，总额不变。旁边还有最小、半池、底池、全下。

没弃牌的人亮底牌，用两张底牌和五张公共牌里最好的五张比大小。牌型从同花顺到高牌，A 可以组成 A-2-3-4-5。有人全下时按投入拆边池。除不尽的那一个筹码，给庄家左手边起第一个赢家。别人都弃牌时不亮牌，底池归还在局里的人。

快捷键：F 弃牌，C 或空格过牌/跟注，Enter 确认加注。摊牌后按 Enter 开下一手。右上角可以关音效。

## 道具

电脑不买、也不用道具。这一手你参与了，并且弃牌或净输了筹码，结算后可以花 100 随机抽一张。赢家和旁观的人不能抽。身上同时只能有一张。花掉的 100 离开牌桌，不进底池。同一结算画面不能抽第二次。这一屏用过半退，也不能再抽。望牌、换牌、交换用在牌局里，不影响这手结算后再抽。用错了不消耗。重新开始会清掉手里的牌。

| 牌 | 何时用 | 效果 |
| --- | --- | --- |
| 望牌 | 轮到你下注 | 选一名还在局里的对手，随机亮出他两张底牌中的一张。只你看得见，只限这一手。 |
| 换牌 | 翻牌前，轮到你 | 点自己一张底牌，换成牌堆下一张，旧牌烧掉。 |
| 交换 | 轮到你下注 | 和一名还拿着两张底牌的对手对换整副底牌。你立刻看到换来的牌，对方的牌扣着。双方被望过的牌都会盖回去。 |
| 半退 | 结算后，这手净亏损大于 0 | 退回亏损的一半，向下取整，最多 80。可以把筹码从 0 拉回来。 |

## 联机

一个进程只开一个房间。底牌只发给本人，望牌只发给使用者，摊牌才把没弃牌的底牌发给所有人。有人断开后，那个座位立刻变成电脑，用剩下的筹码接着打，这一手不能换回真人。牌局结束后房主可以重开，人还留在房间里。房主也可以在开局前改人数，不能少于已加入的人数，最多 7 人。

## 文件

- `index.html`、`game.js`、`style.css`：页面
- `engine.js`：规则，页面和服务器共用
- `server.js`：本机房间，端口 8787
- `faces/`：座位头像
